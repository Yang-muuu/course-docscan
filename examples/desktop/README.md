# 桌面程序演示照片

本目录图片均为合成样例。左右页由 `src/docscan/samples.py` 中的「校园阅读计划」和「城市雨水观察」渲染。字形来自 Noto Sans SC。

| 文件 | 选择的扫描模式 | 生成过程 |
| --- | --- | --- |
| book-spread.jpg | 摊开书籍 | 拼接两张不同的渲染页，并添加深色书脊 |
| same-page-1.jpg、same-page-2.jpg | 同页多拍 | 给同一张渲染页加入桌面背景。第二张另加阴影和小角度旋转 |

普通纸张模式使用 [单页样例](../synthetic/sample.jpg)。程序内的「打开示例」会导入该图片。
